# ENZO V1 — Power & 5V Isolation Wiring (Schottky Channels)

**Status:** As-built / Canon reference

This document records the three external **SR560** Schottky paths used in **ENZO V1** with the Waveshare ESP32-S3-DEV-KIT-N8R8. All three external diodes were the same part: SR560, rated 5A average forward current, 60V repetitive peak reverse voltage and 150A non-repetitive forward surge. The original builder reported working operation on battery only, USB only and with both connected; that historical result does not guarantee arbitrary substituted converters.

The board schematic shows USB VBUS → onboard D1 (B5819WS) → VDDUSB, which is connected to the ESP board 5V header. D1’s cathode is on the board side. The two external ESP/rail diodes provide opposite-direction supply paths between the same two nodes; onboard D1 provides the USB-side reverse block.

Manufacturer schematic: https://files.waveshare.com/wiki/ESP32-S3-DEV-KIT-N8R8/ESP32-S3-DEV-KIT-N8R8-schematic.pdf

## 1. Power Source Overview

### Battery Path
```
Battery → Fuse → Schottky (reverse protection) → Source Rail → Buck Converter → Latching Switch → 5V Rail (A)
```

### USB Path
```
USB VBUS → onboard D1 → ESP32-S3 5V header → external Schottky Channel A → 5V Rail (A)
```

---

## 2. 5V Rail Isolation (Dual-Schottky Scheme)

### Channel A — USB / ESP → Rail
- From: ESP32-S3 5V pin
- To: 5V Rail (A)
- Diode orientation: Grey band faces the rail

### Channel B — Rail → ESP
- From: 5V Rail (A)
- To: ESP32-S3 5V pin
- Diode orientation: Grey band faces the ESP

## 3. 5V Rail Loads

### Required / normal Free V1 loads
- Latching switch LED
- RGB / NeoPixel eyes
- PIR
- ESP32-S3 (via Channel B)

### Historical / optional / later loads seen on the physical ENZO build
- Voltmeter
- OLED
- DHT22

The optional/historical items above are **not required Free V1 hardware**. Their presence in as-built references does not change the Free V1 BOM or staged build requirements.

## 5. Integrated USB State and Component Limits

USB can feed the rail downstream of the latching switch, so button OFF does not guarantee a dead 5V rail after ESP integration. Historical V1’s fixed RC-style UBEC tolerated the documented combined-source state in use, but its exact brand/SKU and reverse-drive specification are unavailable; do not generalise that behaviour to a substitute converter.

Combined battery + USB operation is only a supported V1 state after the three SR560 paths, common ground and latching-switch wiring are installed and both single-source checks pass. If a substitute UBEC does not explicitly permit its output to be externally driven, leave the latching switch OFF while USB is connected. Disconnect battery and USB before changing wiring.

**The documented V1 topology is preserved. This clarification does not propose replacement circuitry.**
